# Project Statement

## Problem Statement
Most people forget small expenses they make every day, like snacks, transport, small shopping etc. After some days it becomes confusing where the money went. To solve this, I made a simple Python tool that stores these expenses and shows them whenever needed.

## Scope of the Project
The project is kept small and focused. It only handles three things:
1. Adding an expense
2. Viewing all saved expenses
3. Summary of total spending and category wise spending

Everything happens through a simple text-based menu.

## Target Users
Anybody who wants to keep a basic record of their daily expenses.  
Students, working people, homemakers — anyone can use it.

## High-Level Features
- Menu driven interface  
- Add expense with amount, category, description  
- View all expenses  
- Summary calculation  

I kept the project simple to make sure it aligns with what we learned in the flipped course and can be easily understood by anyone.
